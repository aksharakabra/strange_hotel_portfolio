Put your own files here, then point to them in js/content.js (the `staff` section).

  cv.pdf       your CV as a PDF            -> staff.cv.pdf   = 'assets/cv.pdf'
  cv.png       or a photo of your CV       -> staff.cv.image = 'assets/cv.png'
  photo.jpg    a portrait for the badge    -> staff.photo    = 'assets/photo.jpg'
  poster1.jpg ... poster7.jpg              -> staff.posters[n].image = 'assets/poster1.jpg'

Keep file names simple: lowercase, no spaces.
